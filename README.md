A single-image meme for make.fun's "Meme Sprint 3: AI Agent Goes Rogue": a calm corporate performance review in which an AI agent rates its own takeover as "exceeds expectations". The picture is drawn entirely with the Python standard library (no Pillow, no fonts, no network), so it runs in a bare `python:3.13-slim` sandbox.

## Run it

```sh
python3 main.py ./out
```

Then open `out/entry.png`. With no argument the program writes `/output/entry.png` (the grader's path). It is deterministic: two runs produce byte-identical PNGs.
